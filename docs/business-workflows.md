# 词典、文件批次与复杂规则

这组能力把旧业务系统中成熟的管理流程迁入当前 Python 项目，复用现有账号、数据库、Worker 和审计，不额外部署旧 Java 应用。

## 页面操作

进入“业务数据与词典”，可在现有申报、风险与词典列表下方操作：

1. 选择导入对象、词典类型和数据环境，下载空白模板。
2. 上传 UTF-8 CSV 或单工作表 XLSX，最大4 MiB、5000行。
3. 查看批次进度、逐行错误与结果报告。发现一行错误则整批不入业务库，修正文件后创建新批次。
4. 对导入词典点击“查看导入词典”，勾选条目后确认、撤销确认、改名、切换主词、拆组、合组、移动或删除。
5. 调整生成新版本；业务词典需审核发布，历史版本保留。可撤销当前发布，或选择祖先版本生成回退草稿，再审核。
6. 导出当前申报、风险记录、词典条目、词典版本或治理报告。导出也作为任务运行，限定最多5000行、32 MiB，不静默截断。

导入环境为“业务”只表示数据来源属性，不表示词典已审核。合成环境不能审核发布到正式词典。导入风险记录不会自动补出风险覆盖策略，需独立审核已有范围和映射。

## 文件列

- 词典：`term`、`canonical`、`element_code`、`element_name`、`scope`、`frequency`、`payload`。`term`必填；其余可留空，`payload`是规则对象的JSON文本。
- 申报：`code_ts`、`description`、`elements`。`elements`是含`code/name/value`的JSON数组，每个要素必须明确编码，不通过位置猜测映射。编码需以文本保存以保留开头零。
- 风险：`knowledge_id`、`fit_area`、`element_code`、`vocabulary`、`threshold`。范围使用2—10位编码前缀，阈值0—1；本入口不接受未经解析的复杂范围。

空模板只含列名，不携带业务样本。XLSX公式、宏、多工作表、超大展开内容会被拒绝。CSV报告对可能被电子表格执行的公式前缀进行转义。词典、申报和风险数据导出采用对应列约定；版本元数据与治理报告导出用于查看和审计。

## 版本与组操作

条目保留规范词、要素、范围、词频及状态。同义/规范词支持组操作，其他词典支持新增、确认、撤销确认、改名和删除。

主词切换会同时更新该要素与章节范围内的同组条目。拆组和移动仅影响选中条目。跨要素、跨章节、正反极性混组、重复条目以及无效选择会整次回滚。编辑请求携带快照指纹；发布、撤销等导致快照变化后，旧界面必须重新加载。

回退不覆盖历史版本，只允许同一谱系的祖先。撤销发布使当前版本失效，不暗中启用另一个历史版本。发布时串行检查谱系，过期并行分支不能同时生效。

## 跨要素互斥和配置评分

在互斥、归类互斥或评分词典中，可通过“新增词条或跨要素规则”维护两个条件；文件/API支持最多十个条件。每个条件明确要素编码或名称及词组：同一条件内任一词匹配，条件之间全部满足才触发。

规则只从对应结构化要素或明确的`字段：值`文本取值，不把另一个字段中的词借过来，也不对否定子句作正向命中。章节范围仍由词典策略限制。命中记录携带匹配字段与词，便于复核。

规则分数是人工配置的有限数值，范围-1000到1000；不是训练得到的概率，也不替代Agent终评。当前没有迁入旧 Java 全部评分训练和人工归类编组体系。

## 执行与故障语义

批次复用`jobs`的幂等键、租约、心跳、有限重试、取消和事件；附件与逐行进度分别存入`asset_batch_files`、`asset_batch_rows`。上传文件不放在任务JSON或前端包内。

逐行验证写入进度，最终业务入库与任务完成使用同一租约保护事务。取消/过期Worker不能提交；中途故障可从相同附件重新校验，行记录按批次及行号覆盖，不重复累积。相同文件和参数再次提交可复用已导入数据。

导入/导出不创建生成模型请求，不调用付费API。文件错误记录在批次内，错误报告不打印密钥或服务响应。生产数据、附件和报告仍只保存在私有数据库中。

## API 与部署

- `GET /v1/business/templates/{dictionary|bill|negative}`：空白CSV模板。
- `POST /v1/business/imports`：原始文件请求体，查询参数指定filename、asset_kind、dictionary_kind、name和synthetic；需幂等键。
- `POST /v1/business/exports`：按类型、词典及环境创建导出任务。
- `GET /v1/business/batches`、`/{id}`、`/{id}/report`：批次、逐行进度、完整/错误报告。
- `POST /v1/tasks/{id}/cancel|retry`：复用现有任务控制及角色权限。
- `GET /v1/business/dictionaries/{id}`：快照、条目及历史祖先。
- `POST .../{id}/operations|restore|withdraw`：批量修订、回退草稿、撤销发布。

发布前备份业务库并执行`alembic upgrade head`，新增迁移`0004_asset_batches`。生产依赖增加openpyxl及et-xmlfile。Nginx模板允许4 MiB文件请求；其他代理也需同步限制。账号、CSRF、审核角色沿用现有实现。
