# 数据契约与公开范围

发布算法、工作流、前后端、迁移、通用部署及评测脚本。`tests/` 和界面启动器用代码即时生成极小合成样本，验证接口、状态与恢复；它们不是业务测试集。

真实报关单、开发/留出集、逐条预测、客户材料、原词典、税则/注释原件、个人简历、凭证、模型权重与日志不公开。截图重新由合成环境生成。首次发布使用全新 Git 历史，不携带原工作区历史对象。

`.gitignore` 排除整个 `data/`、`models/`、私有配置、证书、数据库和运行目录。`scripts/check_public_release.py` 检查 Git 实际跟踪内容，CI 重复执行。

业务文件准备在 `data/private/`，路径由私有 `.env` 指定：

- **税则：** jurisdiction、版本、来源、entries；每条保留编码、父节点、文本和来源，结构分组另行导入。年份与注释版本需核对。
- **风险：** 明确税号适用范围、要素、词、阈值、覆盖与审核状态。不可解析规则不能自动视为覆盖。
- **术语：** 区分同义、规范/非规范、否定、独立、互斥与歧义，保留字段/章节范围。未知词建议独立审核。
- **案例：** 脱敏描述、历史标签、去重分组；历史标签不等于专家裁定。
- **评测：** 冻结开发/留出划分和指纹，排除索引中的同组案例，结果留在私有目录。

导入入口见 `prepare_sources.py`、`import_business_assets.py`、`import_groups.py`、`ingest_notes.py`。源系统格式不同，需核对自己的字段映射；仓库不提供完整底层业务词库。
